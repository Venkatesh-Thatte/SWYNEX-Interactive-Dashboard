# SWYNEX – Interactive Sales Dashboard

## 📊 Project Overview

This project focuses on building an interactive sales dashboard using Microsoft Excel to analyze sales performance and present key business insights through KPIs, charts, summary tables, and interactive filters.

The dashboard helps users understand revenue trends, order distribution, product performance, city-wise sales, and sales representative performance.

## 🎯 Objectives

- Build a clean and professional interactive sales dashboard.
- Track key performance indicators (KPIs).
- Analyze sales performance across products, cities, and sales representatives.
- Present important findings through charts and summary tables.
- Support data-driven business decision-making.

## 🛠️ Tools Used

- **Microsoft Excel**
- PivotTables
- Excel Charts
- KPI Cards
- Interactive Filters
- Data Analysis and Summary Tables

## 📌 Key Deliverables

1. **Interactive Dashboard** – A consolidated view of sales performance.
2. **KPI Cards** – Quick overview of important sales metrics.
3. **Revenue Analysis** – Sales revenue summaries and comparisons.
4. **Product Performance Analysis** – Evaluation of sales across products.
5. **City-wise Sales Analysis** – Comparison of sales across locations.
6. **Sales Representative Analysis** – Comparison of orders sold by each representative.
7. **Charts and Visualizations** – Visual presentation of sales data and trends.
8. **Supporting Data Analysis** – Summary tables and calculations used for analysis.
9. **PivotTables** – Supporting summaries for dashboard reporting.
10. **Business Insights** – Key observations to help understand sales performance.

## 📈 Key Business Questions

- What is the total revenue generated?
- How many orders were recorded?
- Which products contribute the most to revenue?
- Which cities generate the highest sales?
- Which sales representative sold the most orders?
- How does sales performance vary across different categories?

## 📂 Workbook Structure

- **Dashboard:** KPIs, charts, filters, and key insights.
- **Data Analysis:** Supporting calculations, summary tables, and business insights.
- **PivotTables:** Summaries supporting dashboard analysis.
- **Raw_Data:** Underlying transaction data, if included in the workbook.

## 💡 Outcome

This project demonstrates practical Excel skills in dashboard development, data summarization, PivotTables, chart creation, and business performance analysis. It showcases how raw sales data can be transformed into an organized and useful reporting dashboard.
